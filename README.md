# VASILISA.OS — сайт-портфолио Василисы Труновой

Astro + TypeScript, статическая сборка, RU (по умолчанию) и EN (`/en/...`).

## Запуск
```
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
```

## Где что лежит
- `src/data/` — весь контент: проекты, опыт, навыки, образование, услуги, отзывы, цифры. Каждый текст — `{ ru, en }`.
- `src/i18n/ui.ts` — подписи интерфейса (меню, кнопки).
- `src/styles/global.css` — дизайн-система: цвета, шрифты, отступы, окна, папки, чипы.
- `src/components/` — шапка, подвал, окно macOS, папка, карточка кейса.
- `src/views/` — страницы целиком (одна вёрстка на оба языка), `src/pages/` — адреса.
- `src/assets/img/` — фото (сжимаются в WebP при сборке).

Исходные материалы в корне папки (референсы, удостоверения) в репозиторий не попадают — см. `.gitignore`.

## Пометки «добавить материал»
У каждого проекта в `src/data/projects.ts` есть поле `todo` — список того, чего не хватает. Эти пункты видны на странице кейса пунктирной плашкой, пока их не заполнить.

## Публикация
- Свой домен: `SITE=https://ваш-домен BASE=/ npm run build`
- GitHub Pages без домена: `SITE=https://<логин>.github.io BASE=/<репозиторий>/ npm run build`
